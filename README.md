### [PB2 to PB3 map converter](https://github.com/Nyoveee/pb2mapconverter)
Developer of the web application that converts a given PB2 .xml map into PB3 map. Currently WIP, if you want to contribute please let me know via Discord! 😊

### [PB2 Advanced Launcher](https://github.com/Nyoveee/pb2advancedlauncher)
Developer of the PB2 Advanced Launcher, powered by Tauri and React to launch Plazma Burst 2 with profiles. This is used to support the launch of flash PB2 due to Adobe Flash's EOL.

### [PlazmaBot](https://github.com/Nyoveee/plazmabuddy)
Developer of the PlazmaBot discord bot, used to facilitate admistrative task like verification in Plazma Burst discord servers. Originally inspired by PlazmaBuddy from Mrmcshroom. 

### [ALEi](https://github.com/Molisson/ALEI)
Contributor of the ALEi project. ALEI is a extended Plazma Burst Advanced Level Editor supporting new features and editor's QoL. Responsible for the implementation of extended trigger actions.

### [PB2 Works](https://prosuwanted.ru/pb2works)
Contributor of the PB2 Works project. PB2 Works is a PB2 mod featuring advanced features like Lua scripting, much faster rendering API (via Stage3D) and many more. Responsible for a majority of the implementation of Stage3D rendering, and the frontend of the web application.
